Como instalar o Vídeo Fácil no Windows

Instalar leva menos de um minuto. Se aparecer um aviso azul do Windows, fique tranquilo: ele aparece com programas novos que o Windows ainda não conhece.

Passo a passo

  1. Baixe o instalador. Clique em Baixar grátis e abra o arquivo Instalador-Video-Facil.exe.
  2. Se aparecer "O Windows protegeu o computador": clique em Mais informações e depois em Executar assim mesmo.
  3. Clique em Avançar até concluir. O Vídeo Fácil abre sozinho, com 30 dias grátis já liberados.

Dúvidas comuns

Funciona em qual computador?

Windows 10 ou Windows 11, de 64 bits. Não funciona no Windows 7, no celular ou no Mac.

Preciso de cadastro ou cartão?

Não. O teste de 30 dias começa sem cadastro e sem cartão.

Use o programa apenas para vídeos seus ou que você tenha permissão para baixar.
